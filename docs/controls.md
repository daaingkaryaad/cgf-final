# Application controls

| Input | Action |
| --- | --- |
| `Space` | Start the rocket launch sequence. |
| `R` | Reset the rocket, camera, exhaust particles, and pad light. |
| `H` | Return the camera to its home position. |
| `C` | Switch between free and chase cameras; switching back restores the saved free-camera view. |
| `L` | Toggle the launch-pad light. |
| `W` / `S` | Move the camera forward / backward. |
| `A` / `D` | Move the camera left / right. |
| `Q` / `E` | Move the camera down / up. |
| `Left Shift` / `Right Shift` | Move the camera faster. |
| Left mouse click | Capture the mouse for looking around in free-camera mode. |
| `Tab` | Capture or release the mouse in free-camera mode. |
| `Esc` | Release the captured mouse; press again to close the window. |

Mouse movement rotates the free camera only while the cursor is captured. Free-camera movement and mouse look are disabled in chase mode. Switching to chase mode or losing window focus releases mouse capture. `H` and `R` return to the home view in free-camera mode.
