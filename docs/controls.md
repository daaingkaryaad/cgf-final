# Application controls

| Input | Action |
| --- | --- |
| `Space` | Start the rocket launch sequence. |
| `R` | Reset the rocket, camera, exhaust particles, and pad light. |
| `H` | Return the camera to its home position. |
| `L` | Toggle the launch-pad light. |
| `W` / `S` | Move the camera forward / backward. |
| `A` / `D` | Move the camera left / right. |
| `Q` / `E` | Move the camera down / up. |
| `Left Shift` / `Right Shift` | Move the camera faster. |
| Mouse click or `Tab` | Capture or release the mouse for camera looking. |
| `Esc` | Release the captured mouse; press again to close the window. |

Mouse movement rotates the camera only while the cursor is captured. If the application loses window focus, mouse capture is released.
